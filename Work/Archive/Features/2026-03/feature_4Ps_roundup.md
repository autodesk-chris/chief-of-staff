# Feature: 4Ps roundup

## Details

Reviews 4Ps from Slack, compares against MFM outputs. Critiques it to check it is focused on the right things.

## Slack integration (Julie 2.0)

- Read the 4Ps Slack channel using Slack MCP
- Pull each team member's 4Ps for the current week
- Cross-reference progress against MFM summary priorities and focus areas
- Flag misalignment between reported progress and agreed priorities
- Output a team summary highlighting: alignment gaps, common blockers, notable progress
