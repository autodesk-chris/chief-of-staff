# Standing Meetings - Reference Mapping

A lookup table for recurring meetings. The `prep meeting:` workflow checks this **in addition to** its normal context-gathering, it does not replace discovery. If you find a match here, pull from these sources AND continue with your usual sweep (calendar, Granola, recent decisions, contacts, etc.). Treat the entries as priority anchors, not a closed list.

How to use:
- Fuzzy-match the meeting title against the `Title` field (and `Aliases`)
- Pull from listed Slack channels, Confluence pages, prior prep docs
- Use the `Prep style` notes to shape the document
- Use `Cadence` as the soft lookback window for Slack/DM/Granola review (weekly = ~7 days, biweekly = ~14, monthly = ~30). Extend if a thread clearly spans further; don't truncate signal artificially.
- If the meeting isn't here and is clearly recurring, propose adding it after the prep
