
**Hypothesis**

criteria
- User perspective - stated from a users point of view, not Forma's perspective. 
- Belief statement - Clearly states core belief about problem/behaviour, avoids solution framing
- Problem space aligned - Provides rationale that aligns to the problem and connects to supporting data to justify
- Is falisifiable - Can be definitively validated or refuted with specific, measurable outcomes
- Supporting data - is clearly aligned to data insights
- Format - uses 'We believe'. Does not include 'if, 'could' 'should'. Does not use feature or solution framing, 
  
Tests
1. Can the belief be proven false?
  2. Is it written as a belief, not a solution/goal?
  3. Does it connect to the root cause?
  4. Is it logically supported by evidence, without needed tio state specific data points

**Prediction**

Criteria:
- Format - Uses explicit "If... then..." phrasing with clear condition and expected outcome
- Hypothesis connection - Statement clearly connects to the hypothesis, making it possible to validate or invalidate the belief
- Testibility - Outcome is stated in a way that is observable and falsifiable, even without metrics defined yet
- Outcome - Framed at the outcome level, so multiple solution variations could test it

Tests:
  1. Is it written as "If... then..."?
  2. Does it align with the hypothesis by testing its truth?
  3. Can it be observed and proven false?
  4. Could different solution variations be used to test it?
