# Personal growth patterns

This file captures recurring patterns that Chris wants to improve. It also serves as a living log of growth-relevant moments - not just known patterns, but emerging ones too.

Agents should actively look for two things:
1. **Known patterns** - moments matching the documented patterns below
2. **New signals** - anything that suggests a growth area worth reflecting on (e.g., asking for help framing a message, reworking a document multiple times, hesitating on a decision, expressing frustration about a communication)

## Pattern 1: Sharing before aligning with peers

**What happens:** Tendency to move fast and share decisions or information before checking with leadership peers. Can cause friction when others feel bypassed or surprised.

**Example:** Shared that Ammar was becoming interim Engineering Manager before Oyvind had discussed the role with Ammar. Oyvind was very annoyed. (March 31, 2026)

**What good looks like:** Before sharing role changes, org decisions, or sensitive information - pause and ask: "Have all the relevant leaders been consulted/informed?"

**Trigger situations:**
- Announcing role changes or promotions
- Sharing decisions that affect other leaders' teams
- Communicating org changes in Slack or meetings

---

## Pattern 2: Slack communication in contentious discussions

**What happens:** In Slack threads with different points of view, tends to:
- Be too blunt
- Come across as defensive (without intending to)
- Not be as empathetic as intended

**Example:** (to be captured as instances occur)

**What good looks like:** In multi-viewpoint discussions, take a beat to consider how the message reads from the other person's perspective. Lead with acknowledgement before making your point.

**Trigger situations:**
- Slack threads with disagreement or debate
- Responding when feeling challenged
- Topics where people have strong opposing views

## How agents should use this file

### Session logging (when user types "session")
After generating the session summary, review the full conversation for:
- Moments matching known patterns above
- New signals: asking for help with communication/framing, reworking content multiple times, expressing frustration about interactions, hesitation on people decisions, or any moment that suggests personal growth relevance
- If anything is spotted, flag it concisely: *"Growth note: I noticed [specific observation]. Want to add this to your growth log?"*
- If Chris confirms, append to this file under the relevant pattern or create a new pattern section
- If nothing relevant, say nothing - no noise

### Daily summary
Review meeting notes and Slack context for pattern matches or new signals. Flag any relevant moments the same way.

### Active help (real-time during sessions)
- **Slack drafting:** If helping draft a Slack message in a contentious thread, proactively check tone against Pattern 2.
- **Message framing:** If Chris asks for help framing a message or document, note this as a growth-relevant moment at session end.
- **Meeting prep:** When preparing for meetings where sensitive decisions will be discussed, remind about Pattern 1.
- **Document writing:** If Chris asks for help structuring or rewriting communications, note the context at session end.
