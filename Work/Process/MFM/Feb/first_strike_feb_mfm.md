## Review Last Month's Progress

#### Learning & user insights

Concluded two experiments:

- [**Homepage Recommendation Experiment**](https://mixpanel.com/s/3S2gQ1)  
    **Target:** KR1 - Site Entry  
    **Test:** added a recommendation tab to the “Create a Site” option on the Homepage, mainly exposed to non-ACC users.  
    **Outcome:** This delivered a 8%/5ppt lift in Site entry rates.  
    **Learning:** Even small interventions which feel personalized, can drive user actions.  
    
- [**Site Design Analysis Tutorial Experiment**](https://mixpanel.com/s/bf9Dg)  
    **Target:** KR2 - Run 1st analysis  
    **Test:** Automatically trigger tour for all new users who created a Site to show them how to trigger and view results of an analysis. Two test cohorts shown the same tour run on intercom and hard coded.  
    **Outcome:** No significant difference between intercom/hard coded. Both delivered a >30% lift in new users running their first analysis.  
    **Learning:** Most users who clocked into the tour, completed. Drop off rates after second step were close to 0%, suggesting tutorials are a good way to show value to users motivated by the outcome tutorials deliver.
    

**Next step based on learnings:**  
Continue onboarding experiment series.

## Blockers, Dependencies & Asks

### Blockers/Delays

**Delay: Data gathering takes too long**  
**Issue:** Data gathering takes too long due to a) too few users in Site Design, leading to up to four weeks needed for experiment results, and b) too few surfaces with enough meaningful traffic to run experiments (Site design, Home page, Project page). This limits our capacity for simultaneous experiments and velocity.  
**Mitigation:** Consider which product experience, cohort or other slicing could provide the same learning, in parallel to current proposed efforts. Look at ways outside product to get learnings faster or in parallel, i.e. user interviews.

**Delay: Changes negatively impact velocity**

**Issue: changes to org and operations slow velocity,**  
Changes to the org, like downsizing, introduce uncertainty and slows progress. New operating model could have similar effects, with long-lasting impact.  
**Mitigation:** Plan around shifting capacities. Adopt new operating model with consideration. Only implement changes when relevant and valuable. Communicate reasoning and need clearly.

**Issue: Shifting focus impact velocity.**  
External outsize asks for discovery or input keep PMs at just-in-time delivery of squad work, like building a backlog and keeping rituals consistent.  
**Mitigation:** Not engage with asks until outcome, resource demand and task ha been clearly defined, and work has been prioritized agains other workstreams.
